# 🎵 Projeto Música & IA: Composição Generativa com Gemini e Suno

## 📝 Descrição do Projeto

Este projeto explora a intersecção entre criatividade humana e Inteligência Artificial. Utilizando técnicas de **RAG (Retrieval-Augmented Generation)** através do Gemini Gems, foi criado um assistente especializado na análise lírica de **Kendrick Lamar**. O objetivo final foi a produção de um EP com 5 faixas inéditas, cujas letras foram geradas pela IA e a produção musical realizada via Suno AI.

## 🛠️ Tecnologias Utilizadas

* **Gemini Gems:** Criação de base de conhecimento e geração de letras com RAG baseado no estilo de Kendrick Lamar.
* **Suno AI:** Geração de áudio completo — vocais e arranjos instrumentais.
* **GitHub:** Documentação e versionamento do projeto.

## 📄 Processo de Criação

1. **Curadoria:** Seleção de letras representativas de Kendrick Lamar cobrindo diferentes fases e álbuns — *good kid, m.A.A.d city*, *To Pimp a Butterfly* e *DAMN.* — para cobrir vocabulário, métrica e temáticas.

2. **Configuração do Gems:** As letras selecionadas foram inseridas como base de conhecimento no Gemini Gems. O assistente foi instruído a imitar o flow, o uso de duplos sentidos, referências culturais e a estrutura lírica característica de Kendrick Lamar.

3. **Prompt Engineering:** Foram definidos temas inéditos para cada faixa (identidade, lealdade, ambição, pressão social e ascensão) e os prompts foram refinados para garantir consistência estilística com o artista.

4. **Produção no Suno AI:** Cada letra foi inserida no Suno AI com prompts de estilo detalhados (gênero, BPM, instrumentação, mood) para garantir que a sonoridade complementasse o conteúdo lírico gerado.

5. **Documentação:** Todo o processo foi organizado e versionado neste repositório público.
